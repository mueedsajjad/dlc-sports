# dlc-sports

Tournament score card and points reference for DLC Sports.

## Score card (GitHub Pages)

After Pages is enabled, the score card is published at:

**https://mueedsajjad.github.io/dlc-sports/**

Enable once in the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

The site is a static `index.html` with game formats and winner / runner-up points.
